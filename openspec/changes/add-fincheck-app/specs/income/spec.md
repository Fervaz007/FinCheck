## ADDED Requirements

### Requirement: Register income
The system SHALL allow the user to register an income entry with description, category, amount, date, frequency, and optional notes.

#### Scenario: Register a one-time income
- **WHEN** the user registers income "Trabajo extra" for $1,500 on a specific date with no recurrence
- **THEN** the system SHALL store it with `recurring_transaction_id = NULL`, marking it as manual/único

#### Scenario: Register a recurring income
- **WHEN** the user creates a recurring income "Sueldo" of $4,900 with a semimonthly-fixed recurrence
- **THEN** the system SHALL create a `recurring_transactions` row of kind `income`, and future occurrences SHALL be generated by the reconciliation process, each linked via `recurring_transaction_id` and `occurrence_date`

### Requirement: List and filter income by month
The system SHALL allow listing income entries filtered by month, and SHALL sum them for that month's totals.

#### Scenario: View income for a given month
- **WHEN** the user opens the Movimientos screen for September 2026
- **THEN** the system SHALL show all income entries whose `occurrence_date` (or manual `date`) falls within September 2026, and their sum

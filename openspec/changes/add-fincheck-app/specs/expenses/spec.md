## ADDED Requirements

### Requirement: Register expense
The system SHALL allow the user to register an expense entry with description, category, amount, date, frequency, payment account, and optional notes. The system SHALL NOT assume every expense is a debt.

#### Scenario: Register a one-time expense
- **WHEN** the user registers expense "Cena" for $350 paid from the "Efectivo" account with no recurrence
- **THEN** the system SHALL store it with `recurring_transaction_id = NULL`

#### Scenario: Register a recurring expense
- **WHEN** the user creates a recurring expense "Internet" of $600 with a monthly-day-10 recurrence
- **THEN** the system SHALL create a `recurring_transactions` row of kind `expense`, and future occurrences SHALL be generated by the reconciliation process

#### Scenario: Expense category is independent of debt tracking
- **WHEN** the user registers a grocery expense
- **THEN** the system SHALL NOT create or affect any row in `debts` or `debt_payments`

### Requirement: List and filter expenses by month and category
The system SHALL allow listing expenses filtered by month and/or category, and SHALL sum them for reporting.

#### Scenario: View expenses grouped by category for a month
- **WHEN** the user views the expense distribution for September 2026
- **THEN** the system SHALL group all expense entries with `occurrence_date`/`date` in that month by category and show each category's total
